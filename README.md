# Claude Code Sysadmin Workspaces Index

Index of Claude Code workspace templates for systems administration — servers, Proxmox, Docker, NAS, LAN management, Home Assistant, and more. These repos provide structured CLAUDE.md configurations for using Claude Code as a co-administrator for infrastructure.
